# Administrador_Media
Aplicacion de Java para escritorio, pretende poder administrar y consultar el consumo de diversa media (Literatura, Cine y Videojuegos) 

# Descripcion
Adminiatrador de media es un administrador digital y PERSONAL de consumo de distinta media, en este caso sobre cine, literatura y videojuegos, este sistema nos permite como usuarios poder registrar distintas obras de los medios ya mencionados para poder llevar un seguimiento de su consumo, asi como una calificacion y/o opinon de la misma
Creado principalmente como un proyecto de practica, tambien busca que el usuario pueda consultar el registro de los consumos realizados.
